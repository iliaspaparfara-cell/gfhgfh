# UtilityMod (1.8.9 Forge) - source only

1. Download the Forge 1.8.9 MDK (1.8.9-11.15.1.2318) and copy its `gradlew`, `gradlew.bat`
   and `gradle/` folder into this directory (needed for the wrapper). Use Java 8.
2. `gradlew setupDecompWorkspace` then `gradlew eclipse` or `gradlew idea`
3. Run: `gradlew runClient`   Build jar: `gradlew build` (jar in build/libs)

Controls: RIGHT SHIFT opens ClickGUI. Left click toggles a module, right click expands settings,
middle click (or click then press a key) binds. Drag sliders. ESC while binding clears.

Modules: AimAssist, AutoClicker, Timer, Sprint, FastPlace, Fullbright, ESP, Tracers, ArrayList.
Use in singleplayer / your own server / where allowed. Combat modules get you banned on public servers.
